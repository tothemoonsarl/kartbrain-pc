# KartBrain pour PC

Les installateurs de **KartBrain pour PC** (Windows et macOS) et leurs mises à jour automatiques. Le code vit ailleurs ; ici, seulement les releases.

**Télécharger** : [la dernière version](https://github.com/tothemoonsarl/kartbrain-pc/releases/latest) — `KartBrain_x.y.z_x64-setup.exe` pour Windows, `KartBrain_x.y.z_universal.dmg` pour macOS.

Les installateurs ne sont pas encore signés : Windows affiche SmartScreen (« Informations complémentaires » › « Exécuter quand même »), macOS demande un clic droit › Ouvrir. Une fois installée, l'application se met à jour d'elle-même.
